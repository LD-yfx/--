## 方法贡献与实验边界

项目的研究贡献候选是：将模块一稀疏、会过期的跨模态质量证据，转成有明确数学定义与故障行为的导航代价，并用基线和消融检验其作用。A*、Nav2、幂函数和感知质量路径规划已有研究基础，不能单独声称首创。

离线稀疏、陈旧压力场景中，完整模型会绕开人为设置的低质量区域，但路径从 38 m 增至约 56.49 m；高方差场景没有体现出绕行收益。参数未经过独立真实数据标定，不声称完整模型普遍优于线性模型。

滑动窗口会遗忘好、坏证据，过期坏格可能降低到未知惩罚。年龄单调性质只适用于其他统计量固定的代价函数，不是整个窗口系统的时间单调保证。

ROS 管线使用合成传感器；Nav2 闭环使用人工质量场和理想里程计的二维运动学模拟器。二者分别验证数据链路和导航机制，不构成真实 SLAM 定位精度改善证据。真实实验还需要独立定位器、参考真值、障碍物地图、正确 TF、机器人参数与传感器标定。模块一 ZIP 未含原始 rosbag，不能从现有质量 CSV 重建这些数据。
