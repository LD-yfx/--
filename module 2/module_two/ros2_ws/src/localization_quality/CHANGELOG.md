# Changelog

## 0.2.0 — 2026-07-27

- 增加视觉曝光、边缘、特征匹配、运动模糊、跟踪状态和协方差；
- 增加LaserScan方向熵/各向异性/走廊退化与PointCloud2 PCA结构质量；
- 实现场景概率、显式光照、几何上下文和监督单模态校准；
- 实现纯NumPy训练、外部OpenCV YAML模型和C++轻量推理；
- 明确 `mlp`、安全覆盖、规则回退和双退化策略；
- 离线/实时统一为有界因果同步，不再选择未来帧；
- 增加压缩图像、PointCloud2、可配QoS、可选odom和TF目标坐标；
- 实时发布质量OccupancyGrid，离线导出CSV/YAML/PGM/PNG/SVG/JSON；
- 增加三场景27运行Gazebo生成、采集、标签、拆分和七组消融工具；
- 完成27条正式bag、运行级16/5/6划分、正式模型和七组消融；
- 正式测试场景F1 0.8927、权重MAE 0.0841、失效AUROC 0.9809；
- 实时/离线1329帧完整一致，质量和权重差异P95小于5e-7；
- 正式模型使用可移植package URI，缺失或异常仍明确规则回退；
- 保留v0.1规则代码和旧bag为回归，不把bootstrap结果称为正式验收。

## 0.1.0 — 2026-07-19

- 把激光、视觉评分和融合逻辑拆分为可独立测试的核心库；
- 增加实时 ROS2 节点，与离线评估器共用同一算法；
- 增加 ROS2 参数文件，消除用户路径、话题和阈值硬编码；
- 使用消息头时间戳、最近邻离线同步和实时新鲜度检查；
- 增加原始特征、EMA、迟滞、单失效和双失效安全状态；
- 把故障模拟从“修改最终分数”改为“修改原始传感器数据”；
- 增加单元测试、三场景脚本、结果校验器和 SVG 质量地图；
- 使用项目内 3.2 GiB bag 重新生成并校验正式结果；
- 修正包名、数据规模、话题频率、实验表格及文档功能边界。
