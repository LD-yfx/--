# 模块一正式实验报告

日期：2026-07-27。平台：Ubuntu 22.04、ROS2 Humble、Gazebo Classic 11、
OpenCV 4.5、Release构建。

## 数据与划分

正式数据为27条独立Gazebo运行：

```text
3场景 × 3光照 × 3独立seed = 27 bag
```

共记录722,970条ROS消息，哈希覆盖字节8,074,567,882。每条bag均通过
消息类型、必需话题和95%原生频率合同。数据集内容摘要和聚合哈希见
`results/formal_training/formal_dataset_summary.json`。

数据按完整运行划分为16/5/6条训练/验证/测试序列。三个集合都覆盖三场景、
三光照以及seed绑定的正常/视觉退化/激光退化与低/中/高几何复杂度；同一
轨迹完整归属一个集合。监督训练共35,825帧。

## 正式模型

模型：`models/context_mlp_formal.yaml`。

- 训练：纯NumPy Adam，学习率0.0003，批量128；
- 场景网络：11→16→8→3 Softmax；
- 融合网络：10→32→16→2 Softmax；
- 模型选择：以完整运行验证集的权重MAE早停并恢复最佳轮次；
- 模型SHA-256：`44b2df270c9e19aa4ea2045eb5fb41b7c5bc1fafb9cffc9fa27ecaab485603be`。

视觉校准器显式使用定位跟踪状态和协方差评分。这使暗光图像本身都接近
零分时，仍能区分“暗但定位在跟踪”和“视觉定位已丢失”。

## 基线与消融

测试集定位可靠性损失越低越好：

| 方法 | 损失 | 相对规则改善 |
|---|---:|---:|
| 固定0.5/0.5 | 0.38590 | -17.17% |
| 质量比例规则 | 0.32930 | 0 |
| 单模态质量MLP | 0.17597 | 46.57% |
| 完整上下文MLP | 0.16521 | 49.83% |
| 光照+几何上下文 | 0.17576 | 46.63% |
| 场景+几何上下文 | 0.16034 | 51.31% |
| 场景+光照上下文 | 0.17533 | 46.76% |

完整上下文优于固定、规则、单模态质量、光照+几何以及场景+光照方案。
场景+几何方案略优于完整模型，表明当前27运行矩阵中光照与seed绑定因素
存在冗余或仿真域偏差。当前证据支持上下文整体增益；各分量的独立贡献
将在解耦变量的数据矩阵中继续评估。
